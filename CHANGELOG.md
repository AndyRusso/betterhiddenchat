# Changelog
## [1.2.0](https://github.com/AndyRusso/betterhiddenchat/releases/tag/v1.2.0) - 2026-01-22
### Added
- 1.21.9-1.21.11 support
- help subcommand with configuration info and helpful links

### Changed
- `notifyAsOverlay` defaults to overlay instead of chat message
- `showWhileTyping` is now enabled by default

### Removed
- 1.19-1.21.8 support

## [1.1.0](https://github.com/AndyRusso/betterhiddenchat/releases/tag/v1.1.0) - 2023-07-08
### Changed
- Renamed `togglePersistency` subcommand to `persistency`

### Added
- Added a notification when the chat gets shown, as a chat message or overlay
- Added an option to show chat when typing when it is hidden
- Added configuration via subcommands for features above
